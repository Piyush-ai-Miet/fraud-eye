SEPARATION OF CONCERNS:
============================================================

1. URL CHECKER (/api/check-url)
   - NO ML MODEL
   - Web scraping only
   - Authentic checking
   - Real-time verification
   
   Features:
   ✅ SSL certificate verification
   ✅ Domain age checking (WHOIS)
   ✅ Page content scraping
   ✅ Phishing indicator detection
   ✅ HTTPS validation
   ✅ Domain reputation
   ✅ Hindi warnings with domain name

2. QR CODE SCANNER (/api/scan-qr)
   - ML MODEL BASED
   - Trained on 651K URLs
   - 93.5% accuracy
   - Pattern detection
   
   Features:
   ✅ ML prediction (Random Forest)
   ✅ Attack pattern detection (SQL, XSS)
   ✅ Indian scam patterns
   ✅ Phishing keywords
   ✅ Malicious URL database
   ✅ Hindi warnings with confidence scores

============================================================
URL CHECKER - WEB SCRAPING APPROACH
============================================================

Layer 1: SSL CERTIFICATE CHECK
- Verifies HTTPS validity
- Checks certificate expiry
- Detects fake certificates

Layer 2: DOMAIN AGE CHECK
- WHOIS lookup
- Flags new domains (< 180 days)
- Shows registrar info

Layer 3: PAGE CONTENT SCRAPING
- Scrapes actual webpage
- Detects phishing indicators:
  * Login forms
  * Payment forms
  * Urgent language
  * OTP requests
  * Fake brand names
- Extracts page title
- Detects redirects

Layer 4: BASIC VALIDATION
- HTTPS check
- IP address detection
- Suspicious domain check
- Scam keyword detection

KEY DIFFERENCES
============================================================

URL CHECKER:
- Purpose: Check if website is authentic
- Method: Web scraping + real-time checks
- NO ML model
- Checks: SSL, domain age, content, redirects
- Use case: User wants to verify a website

QR CODE SCANNER:
- Purpose: Detect malicious QR codes
- Method: ML model + pattern detection
- WITH ML model (93.5% accuracy)
- Checks: ML prediction, attack patterns, keywords
- Use case: User scans unknown QR code
