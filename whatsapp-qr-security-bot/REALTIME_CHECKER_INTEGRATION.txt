FEATURES ADDED:
============================================================

1. SSL CERTIFICATE VERIFICATION
   - Checks if HTTPS is valid
   - Shows certificate expiry date
   - Detects fake/invalid certificates
   - Shows issuer information

2. DOMAIN AGE CHECKING
   - WHOIS lookup for domain creation date
   - Flags domains < 180 days old as suspicious
   - Shows registrar information
   - Helps detect newly created scam sites

3. WEB SCRAPING & CONTENT ANALYSIS
   - Scrapes actual webpage content
   - Detects phishing indicators:
     * Login forms
     * Payment forms
     * Urgent language
     * OTP requests
     * Fake brand names
   - Extracts page title
   - Detects redirects

4. REAL-TIME VERDICT
   - Combines all checks
   - Calculates risk score
   - Provides Hindi warnings
   - Shows domain name in alerts
